# 한국경제 AI 교육 포트폴리오

`dist/article.html`, `dist/image.html`, `dist/video.html`, `dist/final.html`은 각각 독립 페이지입니다. `dist/index.html`을 열면 기사 페이지로 이동합니다.

공통 디자인은 `dist/style.css`, 메뉴와 필터·상세창 동작은 `dist/app.js`에서 수정합니다. 각 HTML의 콘텐츠 및 template 안의 상세 내용을 실제 결과물로 교체할 수 있습니다.

현재는 정적 포트폴리오 시안입니다. 서버 업로드·파일 저장 기능은 포함하지 않았습니다. 영상은 재생 파일 대신 스토리보드가 표시됩니다. 사진과 폰트는 인터넷 연결이 필요합니다.

미리보기: `node preview.cjs` 실행 후 http://127.0.0.1:4173/article.html 접속.
